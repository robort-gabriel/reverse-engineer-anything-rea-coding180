# Privacy Policy: Web Buddy by coding180

Last updated: 2026-10-30

Web Buddy is a browser extension by Robort Gabriel · coding180.

## What Web Buddy handles
- **Your OpenRouter API key**, settings, personas, avatars, shortcuts and chat history. These are stored only in your browser (chrome.storage.local) and are never sent to coding180.
- **Your prompts and page content.** When you send a message, Web Buddy sends your conversation, and any page text, screenshots or tool results the agent needs, to OpenRouter (openrouter.ai) with your API key. OpenRouter passes it to the model you selected. Their terms and privacy policies apply to that data.
- **Model availability checks.** To list free models that work, Web Buddy sends a short test message ("Reply with the word OK.") to OpenRouter.

## What we do not do
- We do not run servers that receive your data, and we do not collect analytics or telemetry.
- We do not sell or share your data, and do not use it for advertising or any unrelated purpose.

## Your control
You can delete chats, shortcuts and your API key in the extension, or remove all data by uninstalling it. Web Buddy asks before acting on a website for the first time, and you can stop the agent at any time.
