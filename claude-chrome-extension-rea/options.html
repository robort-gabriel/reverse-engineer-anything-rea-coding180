      Help

      Getting started

      1. Create a free API key at openrouter.ai/keys.
      2. Open Settings, paste the key, then Save API Key and Test connection.
      3. Open the side panel with ⌘E / Ctrl+E or the toolbar icon, pick a persona and ask away.

      Common questions

      A model is rate limited or not responding

      Free models are often busy. Web Buddy only lists free models that passed a live check, and switches to another working one automatically mid-task. Use Re-check in Settings → Model to refresh the list, or switch to Paid for the most reliable results.

      Which model should I use?

      Pick one that supports tool calling, or browser actions won't work. For screenshots you also need a vision-capable model.

      Why does Chrome show “debugging this browser”?

      Clicking, typing and screenshots use Chrome's debugger API. Chrome shows its banner while Web Buddy is acting and removes it when the task ends.

      What data leaves my browser?

      Your messages, and page content the agent reads for your request, go to OpenRouter and the model you chose. Your API key and chats stay in this browser. Avoid using Web Buddy on pages with sensitive information, and keep Ask before acting on in Permissions.

      Persona or system instructions?

      Use either a ready-made persona or My persona, where your own system instructions define the persona. Upload an avatar for any of them by clicking its picture in Settings.
